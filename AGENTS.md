### Android UI

Use Material Design 3 Expressive for app-owned Android UI. Build on the shared Expressive theme and supported components; verify the pinned dependency APIs rather than treating standard Material 3 styling as Expressive. Include this requirement in delegated UI tickets.

Keep reader options in the top controls and the reading-position slider alone at the bottom. Preserve committed reading positions when opening controls or previewing. Verify UI changes on Android with screenshots and restored-anchor evidence.
