# Adopt Readium with an interaction validation gate

We chose Readium for EPUB rendering and navigation so the project can focus on the personal reading experience rather than implementing a publication engine. Adoption is provisional until a focused Android prototype proves custom word lookup, persisted highlights, and scrolling/nested note overlays without moving the main reading position. The hyperlink API is experimental and generic endnotes may need app-owned extraction, so a failed prototype can reopen the engine choice before substantial application work.
