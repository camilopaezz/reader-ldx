# Issue tracker

Use GitHub Issues in camilopaezz/reader-ldx through the gh CLI.

- Publishing a spec or ticket means creating a GitHub issue.
- Read the full issue body, labels, and comments before working on it.
- Use --body-file for multiline issue bodies and comments.
- Publish tickets in dependency order.
- Use native sub-issues and blocking relationships when available.
- Otherwise record Parent and Blocked by references in issue bodies.
- Start a ticket only when its blockers are complete.

PRs as a request surface: no.
