# Reader UI pass

Issue [#11](https://github.com/camilopaezz/reader-ldx/issues/11) implements the owner's requested top controls, bottom slider and Material Design 3 Expressive. Implementation and Android checks are complete; appearance remains available for owner review. Compatibility issues #9 and #10 remain unresolved. The combined engine gate is still **FAILED**, and #8 remains open.

## Implementation and build

Source commits `7e77de2` and `a2e6067` were implemented in isolated branch `prototype/11-reader-ui`, then integrated into `prototype/android-reader` at `db6a60e`. `de27bb0` adds the Expressive requirement to AGENTS.md so future delegated UI tickets inherit it. No ReadingEngine, SliderController, dictionary matching, Room or DataStore implementation changed.

The top area contains Library, Aa, bookmark, overflow and Close, with Return or Cancel preview below that toolbar. Overflow contains annotations, dictionaries and separate prototype diagnostics. Aa opens a dialog; opening it does not reflow. Center tap still reveals controls. Previous/Next buttons were removed from normal chrome; edge taps and swipes remain the page-navigation routes. The bottom contains only the reading-position slider and its small reading/preview label. Temporary lookup, passage actions and book-note overlays retain their existing roles.

This uses actual `MaterialExpressiveTheme`, `MotionScheme.expressive`, `HorizontalFloatingToolbar`, `IconButtonDefaults.shapes` and `ButtonDefaults.shapes`. Material3 is pinned to `1.5.0-alpha02`, Compose UI/Foundation/Layout to resolved `1.8.2`, Runtime/Saveable to resolved `1.9.0`, AndroidX Annotation to resolved `1.9.1`. The [official release notes](https://developer.android.com/jetpack/androidx/releases/compose-material3#1.4.0-beta01) explain the move of Expressive APIs out of stable 1.4; [alpha02](https://developer.android.com/jetpack/androidx/releases/compose-material3#1.5.0-alpha02) includes a slider keyboard fix. Keyboard behavior was not exercised here. JDK21, Kotlin2.1.21, Gradle8.14.1, AGP8.10.1, compile/target36 and Readium3.1.2 remain pinned. See [resolved dependencies](dependencies.txt).

Initial source build passed in 52 seconds. The lookup correction passed in 7 seconds. The integrated `assembleDebug` plus public dictionary test passed in 32 seconds, with one test, zero skips, zero errors/failures, 3.331 seconds. See [integrated log](integrated-build-test.log) and [test XML](dictionary-public-test.xml).

Delivery APK: `android/app/build/outputs/apk/debug/app-debug.apk`, SHA256 `de8e42d349fd9e3cd8c9b0f0374bd13871cc394967039fc36b165ce43d2019f1`. It was installed with preserved data and exercised for top controls, dictionary access/native lookup, rendered slider preview and force-stop restoration. The broader final-source run used the isolated build of the same source, SHA256 `3fae41da8e3925c7d7002567fa10c243082287449637ece8d7996086ffe87e9c`. Earlier chrome checks used `39f3757ccb2302ce74cd78cda7da703e6e7e2e829b61c31225697b6db4c5a103`, before the lookup-only correction. These hashes identify separate build artifacts rather than claiming one APK covered every action.

## Reproduce and review

Use the [Android build/import instructions](../../../android/README.md). Preserve app data with `install -r`; do not downgrade schema2 or clear data. Open Generic nested note fixture or the Spanish foundation fixture from Library. Use center tap to reveal controls, Aa for reflow, top overflow for dictionaries/annotations/diagnostics, the bottom slider for preview, Cancel or Back for restoration, and a clear page tap for commitment. Compare `COMMITTED`, `VISIBLE`, `SLIDER_*` logs and database snapshots with `capture-state.py`. Coordinates above belong to this recorded device/typography; use fresh snapshot refs for controls on another setup.

An [independent review](review.md) found no remaining blocking source defect and confirmed actual Expressive use. Keyboard navigation, TalkBack, large system fonts, dark mode and physical-phone ergonomics are untested. Narrow and landscape evidence covers controls/menu fit, not all overlays or rotation interruption combinations. Annotation list and selection routes were reached; all CRUD and dictionary-import permutations were not rerun for this styling pass. Block-level resume precision remains the prototype's existing limit.

Owner review: assess top toolbar size/spacing, Return placement, slider-only bottom and the compact lookup source picker. The page-tap commitment, single Return swap, Back policy and other provisional interactions remain pending in [the combined review](../issue-8/owner-review.md). Appearance acceptance does not pass the failed compatibility gate.
