## Storage and evidence boundary

`annotations.db` is a separate local Room database so this ticket does not alter the foundation's book/reading-position schema or another feature's migration. The imported-book SHA256 identifies its records. Passage annotations store complete Readium publication-relative locator JSON, exact excerpt, color and editable note. Bookmarks store the committed paragraph/block locator. Intentional Open passage navigation uses `navigateCommitted`; it does not create slider return state.

The engine checks Highlight style support, applies actual Readium decorations, handles decoration activation, and reapplies the Room records after every navigator reconstruction. Readium3.1.2's view model stores decoration groups and renders them on resource load, so reapplication does not depend on a preloaded DOM. Source plausibility is not a check result. Runtime `ANNOTATION_RENDERED` logs report Readium's resolved DOM range text, start/end IDs and offsets and rendered box count. `ANNOTATION_SAVED` and `ANNOTATION_RESTORED` record source and durable locator JSON.

### Failure and next step

Native cross-page range extension is not demonstrated by the controlled attempt above. Keep the parent selection check failed. The limitation is at the native selection/engine interaction boundary in this geometry; further diagnosis must distinguish a handle-hit/automation limitation from Readium's horizontal-column selection behavior. Next step is a recorded manual owner attempt at this same boundary, then, if it also fails, investigation of an app-owned range-extension interaction or another engine. A programmatically injected range would test decoration rendering but would not pass the required native selection check. No such substitute was counted as a pass.

Cross-chapter selection, arbitrary EPUB markup, a range containing a note link, English annotation text, lookup on highlights and actual bookmark/list versus slider-history interaction were not exercised in this isolated ticket. They remain separate combined checks or limits. This bounded ticket investigation can complete with the documented cross-page failure; the adoption gate remains failed.

## Provisional choices and remaining limits

Explicit Save is the durability boundary. Cancel and Android Back discard an unsaved editor draft. A saved note decorates its selected passage with the same highlight mechanism. The list groups by chapter label from the EPUB contents, falling back to locator title/resource name. Grouping and this combined editor need owner review. Bookmark/list navigation is ordinary committed navigation. Combined lookup/menu and slider-history checks belong to #8.
