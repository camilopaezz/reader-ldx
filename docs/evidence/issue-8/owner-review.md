The combined marked-note preview sample verifies Back closes the note while leaving preview, then lookup Back followed by preview cancellation restores the source. Native selection can consume Back separately; diagnostic lookup has fewer layers. Warm lookup can recreate native selection and reset its source to the book-language default, as the dictionary slice observed. Retention of every chosen source, scroll position or native selection is not promised. Outside dismissal within nested notes is implemented by the same Back callback, but this combined run does not independently exercise every outside-tap variation.
